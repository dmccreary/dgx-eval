# References: Prerequisites and the Intelligent Textbook

1. [Git](https://en.wikipedia.org/wiki/Git) - Wikipedia - Describes Git's history, distributed design, data structures, commands, and merge strategies. Explains the version control tool behind this chapter's Git and GitHub skills, where every revision of a textbook is committed to a repository.

2. [Markdown](https://en.wikipedia.org/wiki/Markdown) - Wikipedia - Traces Markdown from its original syntax through CommonMark standardization and variants such as GitHub Flavored Markdown. Clarifies the plain-text source format in which every chapter and generated page of this textbook is written.

3. [Hallucination (artificial intelligence)](https://en.wikipedia.org/wiki/Hallucination_%28artificial_intelligence%29) - Wikipedia - Defines AI hallucination, its causes in language generation, and mitigation methods. Supports this chapter's warning that assistant answers can be fluent and slightly wrong, so every result must be checked before it is trusted.

4. A Taxonomy for Learning, Teaching, and Assessing: A Revision of Bloom's Taxonomy of Educational Objectives (Complete Edition) - Lorin W. Anderson and David R. Krathwohl (editors) - Addison Wesley Longman - Replaced Bloom's single list of nouns with action verbs and a two-dimensional table crossing six cognitive processes with four knowledge types. That grid is how learning outcomes and quiz questions are labeled.

5. Understanding by Design (Expanded 2nd Edition) - Grant Wiggins and Jay McTighe - ASCD - Names and systematizes backward design: decide the desired results first, then the acceptable evidence, then the lessons. This is the logic behind writing a course description and learning outcomes before any chapter.

6. [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) - Material for MkDocs Documentation - Official documentation for the theme that turns Markdown files into a searchable static site, with getting started, setup, plugin, and reference sections. Shows how this book's navigation, admonitions, and build are configured.

7. [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) - MIT - Lecture series on the shell, command-line environment, development tools, and version control with Git. Practices the command-line skills this chapter assumes and that every later benchmark step relies on.

8. [The Python Tutorial](https://docs.python.org/3/tutorial/) - Python Documentation - Official tutorial covering the interpreter, control flow, data structures, modules, input and output, and virtual environments. Prepares you to read and run the short Python scripts the evaluation uses throughout.

9. [Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices) - Anthropic Documentation - Vendor guide to writing effective prompts, including being clear and direct, adding context, and using examples. Backs this chapter's habits of stating context and asking for reasoning when working with a generative AI assistant.

10. [The Return of Intelligent Textbooks](https://interactiveaimag.org/columns/the-return-of-intelligent-textbooks/) - AI Magazine - Brusilovsky, Sosnovsky, and Thaker trace intelligent textbooks across four generations, from hand-built domain models to interaction data mining. Gives research context for the intelligent-textbook model this chapter defines.
