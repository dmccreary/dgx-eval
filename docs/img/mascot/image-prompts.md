# Tera the Robot: Pose Prompts

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Each prompt below is self-contained: paste one at a time into your image generator,
keeping the same chat session where possible so the style stays consistent.
Generate at 1024x1024, save with the exact filename shown, then trim padding (see the end of this file).
The identity source of truth is [character-sheet.md](character-sheet.md); every prompt must match it.
