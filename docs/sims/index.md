# List of MicroSims for DGX Evaluation for Textbook Generation

MicroSims are small interactive exercises, each on one concept from a chapter of this book. Select a card to open the MicroSim with its lesson plan.

<div class="grid cards" markdown>

-   **[Agent Loop Stepper](./agent-loop-stepper/index.md)**

    ![Agent Loop Stepper](./agent-loop-stepper/agent-loop-stepper.png)

    Step through the five phases of one agent turn, then choose what the harness does next in six situations.

-   **[Agent Turn Time Breakdown](./turn-time-breakdown/index.md)**

    ![Agent Turn Time Breakdown](./turn-time-breakdown/turn-time-breakdown.png)

    Calculate the time of one agent turn from its tokens, speeds, and tool time, name the part that dominates, then explore five inputs.

-   **[Benchmark Stage Pipeline](./benchmark-stage-pipeline/index.md)**

    ![Benchmark Stage Pipeline](./benchmark-stage-pipeline/benchmark-stage-pipeline.png)

    Open the seven elements of the three-stage benchmark pipeline, then answer four questions about what starts from what.

-   **[Book Levels MicroSim](./book-levels/index.md)**

    ![Book Levels MicroSim](./book-levels/book-levels.png)

    Point at each step of a five-level staircase to compare the levels of intelligent textbooks, from static text to autonomous AI.

-   **[Candidate Model Explorer](./candidate-model-explorer/index.md)**

    ![Candidate Model Explorer](./candidate-model-explorer/candidate-model-explorer.png)

    Compare ten candidate models on a bubble chart of parameter count, generation speed, and download size, then answer five questions.

-   **[CIS Calculator](./cis-calculator/index.md)**

    ![CIS Calculator](./cis-calculator/cis-calculator.png)

    Calculate the concept impact score of six concepts in a small dependency graph, starting from the concepts nothing depends on.

-   **[Command Output Predictor](./command-output-predictor/index.md)**

    ![Command Output Predictor](./command-output-predictor/command-output-predictor.png)

    Predict what five shell commands print, in order, against a small practice directory, and watch the working directory carry over.

-   **[Cost per Textbook Calculator](./cost-per-textbook-calculator/index.md)**

    ![Cost per Textbook Calculator](./cost-per-textbook-calculator/cost-per-textbook-calculator.png)

    Calculate what one generated textbook costs on an owned machine and what it must sell for at a stated margin, then explore five inputs.

-   **[Cost, Price, and Quality Sorter](./cost-price-quality-sorter/index.md)**

    ![Cost, Price, and Quality Sorter](./cost-price-quality-sorter/cost-price-quality-sorter.png)

    Label ten statements about generating a textbook as a cost, a price, or a quality, and see the reason for each.

-   **[DAG Cycle Spotter](./dag-cycle-spotter/index.md)**

    ![DAG Cycle Spotter](./dag-cycle-spotter/dag-cycle-spotter.png)

    Inspect six small prerequisite graphs, decide which contain a cycle, and mark the concepts that lie on it.

-   **[Data Egress Trace Classifier](./egress-trace-classifier/index.md)**

    ![Data Egress Trace Classifier](./egress-trace-classifier/egress-trace-classifier.png)

    Decide where the data in each of eight flows ends up: on the DGX, on the evaluator's own machine, or with a third party.

-   **[Endpoint Exposure Classifier](./endpoint-exposure-classifier/index.md)**

    ![Endpoint Exposure Classifier](./endpoint-exposure-classifier/endpoint-exposure-classifier.png)

    Decide, for six configurations of a local model endpoint, whether a stated party can reach it.

-   **[Environment Reproducibility Auditor](./environment-reproducibility-auditor/index.md)**

    ![Environment Reproducibility Auditor](./environment-reproducibility-auditor/environment-reproducibility-auditor.png)

    Judge whether each of six environment specifications rebuilds the same software on a second machine, and name the reason when it does not.

-   **[Evaluation Design Flaw Finder](./design-flaw-finder/index.md)**

    ![Evaluation Design Flaw Finder](./design-flaw-finder/design-flaw-finder.png)

    Read a described comparison of a local and a cloud model, then judge eight statements about it as a flaw or not a flaw.

-   **[Experiment Variable Role Sorter](./variable-role-sorter/index.md)**

    ![Experiment Variable Role Sorter](./variable-role-sorter/variable-role-sorter.png)

    Assign each of ten items in a model-comparison experiment its role: independent, controlled, measured, or uncontrolled.

-   **[Failure Diagnosis Chooser](./failure-diagnosis-chooser/index.md)**

    ![Failure Diagnosis Chooser](./failure-diagnosis-chooser/failure-diagnosis-chooser.png)

    Attribute each of eight failed-run symptoms to its most likely cause from a list of eight.

-   **[Hardware Finding to Setup Branch Matcher](./hardware-branch-matcher/index.md)**

    ![Hardware Finding to Setup Branch Matcher](./hardware-branch-matcher/hardware-branch-matcher.png)

    Match six hardware probe findings to the setup branch each one triggers.

-   **[Inference Request Path](./inference-request-path/index.md)**

    ![Inference Request Path](./inference-request-path/inference-request-path.png)

    Open the six stages of a chat completion request, then find the stage responsible for each of four described events.

-   **[Learning Graph Defect Finder](./learning-graph-defect-finder/index.md)**

    ![Learning Graph Defect Finder](./learning-graph-defect-finder/learning-graph-defect-finder.png)

    Examine a 16-concept dependency graph and flag the concepts that have one of four structural defects.

-   **[Learning Graph Viewer](./graph-viewer/index.md)**

    ![Learning Graph Viewer](./graph-viewer/graph-viewer.png)

    An interactive viewer for the learning graph each model generated in the benchmark, with search, category filters, and a chooser to switch between models.

-   **[Local Versus Cloud Break-Even Explorer](./local-break-even-explorer/index.md)**

    ![Local Versus Cloud Break-Even Explorer](./local-break-even-explorer/local-break-even-explorer.png)

    Calculate the volume at which a local machine costs the same as a per-book alternative, decide whether one unit can reach it, then explore.

-   **[Local, Cloud, or Hybrid Chooser](./local-cloud-hybrid-chooser/index.md)**

    ![Local, Cloud, or Hybrid Chooser](./local-cloud-hybrid-chooser/local-cloud-hybrid-chooser.png)

    Recommend local, cloud, or hybrid deployment for six scenarios and name the one constraint that decides each.

-   **[Model Shortlist Filter](./model-shortlist-filter/index.md)**

    ![Model Shortlist Filter](./model-shortlist-filter/model-shortlist-filter.png)

    Apply four selection criteria, in order, to eight candidate models and name the first criterion each excluded model fails.

-   **[Model-Fit Calculator](./model-fit-calculator/index.md)**

    ![Model-Fit Calculator](./model-fit-calculator/model-fit-calculator.png)

    Calculate the memory a model needs from its parameter count, precision, and context length, state whether it fits, then explore seven inputs.

-   **[nvidia-smi Output Reader](./nvidia-smi-reader/index.md)**

    ![nvidia-smi Output Reader](./nvidia-smi-reader/nvidia-smi-reader.png)

    Read six outlined fields of an nvidia-smi listing and choose what each one reports.

-   **[Parameters That Fit in Memory](./model-fit-by-memory/index.md)**

    ![Parameters That Fit in Memory](./model-fit-by-memory/model-fit-by-memory.png)

    Move a memory slider to see the largest model whose weights fit in memory, marked by one dashed line on a fixed chart of ten candidate models placed by parameter count.

-   **[Redaction Reviewer](./redaction-reviewer/index.md)**

    ![Redaction Reviewer](./redaction-reviewer/redaction-reviewer.png)

    Judge ten lines of captured output as safe to publish or in need of redaction, and name the category of detail to remove.

-   **[SKILL.md Anatomy](./skill-md-anatomy/index.md)**

    ![SKILL.md Anatomy](./skill-md-anatomy/skill-md-anatomy.png)

    Find the part of a skill folder that answers each of six questions about how a harness uses a skill.

-   **[Structured Output Judge](./structured-output-judge/index.md)**

    ![Structured Output Judge](./structured-output-judge/structured-output-judge.png)

    Judge whether each of six model replies is valid JSON in a required format, and name the defect in each invalid one.

-   **[Tailscale Connection Path](./tailscale-connection-path/index.md)**

    ![Tailscale Connection Path](./tailscale-connection-path/tailscale-connection-path.png)

    Step through how two devices behind home routers build an encrypted connection, then predict paths and sort messages by plane.

-   **[Tailscale Status Reader](./tailscale-status-reader/index.md)**

    ![Tailscale Status Reader](./tailscale-status-reader/tailscale-status-reader.png)

    Read six sanitized lines of Tailscale status output and choose what each one means.

-   **[Testing Architecture](./testing-architecture/index.md)**

    ![Testing Architecture](./testing-architecture/testing-architecture.png)

    Step through how a laptop, two home networks, the internet, Tailscale, and two DGX systems fit together when a local model generates textbook content.

-   **[Textbook Generation Pipeline Explorer](./textbook-pipeline-explorer/index.md)**

    ![Textbook Generation Pipeline Explorer](./textbook-pipeline-explorer/textbook-pipeline-explorer.png)

    Open the eight artifacts of the textbook pipeline, then check which artifacts each generated one is built from.

-   **[Three Kinds of DGX System](./dgx-system-comparison/index.md)**

    ![Three Kinds of DGX System](./dgx-system-comparison/dgx-system-comparison.png)

    Compare three kinds of DGX system in columns, with a drawing of each device, then select the kind that matches each of six descriptions.

-   **[Words to Tokens Estimator](./words-to-tokens-estimator/index.md)**

    ![Words to Tokens Estimator](./words-to-tokens-estimator/words-to-tokens-estimator.png)

    Estimate the token count of six documents from their word counts and decide whether each fits a context window with a 2,000-token reply.

</div>
