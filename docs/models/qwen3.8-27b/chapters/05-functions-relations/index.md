# Functions and Relations

## Summary

This chapter introduces the function as a foundational mathematical relationship. You will distinguish relations from functions using ordered pairs, mapping diagrams, and the vertical line test, and explore domain, range, and function notation across graphs, tables, and rules. You will also evaluate functions, examine linear and nonlinear and continuous and discrete functions, and meet piecewise and step functions, setting the stage for modeling with functions.
