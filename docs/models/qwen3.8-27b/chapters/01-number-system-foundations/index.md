# Number System Foundations

## Summary

This chapter lays the mathematical groundwork for the entire course. You will review the real number system from whole numbers and integers through rational and irrational numbers, along with the number line, absolute value, order of operations, and the commutative, associative, and distributive properties. By the end, you can classify numbers, evaluate expressions using the correct order of operations, and apply the properties of operations as the foundation for every algebraic idea that follows.
