### Completing the Square

Completing the square rewrites a quadratic expression in the form \((x - h)^2 + k\), useful for solving equations and graphing parabolas. It builds on knowledge of exponents and algebraic manipulation.

**Worked Example:** Solve \(x^2 + 6x + 5 = 0\).
1. Move the constant: \(x^2 + 6x = -5\).
2. Add \((6/2)^2 = 9\): \(x^2 + 6x + 9 = 4\).
3. Factor: \((x + 3)^2 = 4\).
4. Square‑root: \(x + 3 = \pm 2\).
5. Solutions: \(x = -1\) or \(x = -5\).

### Graphing Lines

Graphing linear equations involves plotting the set of points that satisfy the equation. The slope‑intercept form \(y = mx + b\) is particularly useful.

**Worked Example:** Graph \(y = 2x - 3\).
1. Identify slope \(m = 2\) and intercept \(b = -3\).
2. Plot the y‑intercept at \((0, -3)\).
3. From that point, rise 2 and run 1 to find another point \((1, -1)\).
4. Draw the line through the points.

### Slope

Slope measures the steepness of a line and is defined as \(\frac{rise}{run}\). It indicates how much \(y\) changes for a unit change in \(x\).

**Worked Example:** Find the slope of the line passing through \((2,3)\) and \((5,11)\).
\[m = \frac{11 - 3}{5 - 2} = \frac{8}{3}\]
