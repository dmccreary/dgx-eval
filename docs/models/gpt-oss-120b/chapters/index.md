# Chapters

This textbook is organized into 10 chapters covering 200 concepts.

## Chapter Overview

1. [Foundations of Algebra](01-foundations-of-algebra/index.md) - Introduces core algebraic variables, constants, operations, and foundational properties that underpin the entire course.
2. [Algebraic Operations – Part I](02-algebraic-operations-part-i/index.md) - Covers basic algebraic manipulations, expressions, and early factoring techniques.
3. [Algebraic Operations – Part II](03-algebraic-operations-part-ii/index.md) - Expands on algebraic operations with rational exponents, radicals, and advanced factoring.
4. [Algebraic Operations – Part III](04-algebraic-operations-part-iii/index.md) - Delves into quadratic formulas, completing the square, and complex factoring strategies.
5. [Functions – Foundations](05-functions-foundations/index.md) - Introduces function notation, domain, range, and basic transformations.
6. [Functions – Advanced Topics](06-functions-advanced-topics/index.md) - Explores advanced function concepts including piecewise, step, and inverse functions.
7. [Data Analysis – Core Concepts](07-data-analysis-core-concepts/index.md) - Presents core data analysis concepts such as data representation and basic statistical measures.
8. [Data Analysis and Statistics – Part I](08-data-analysis-and-statistics-part-i/index.md) - Combines data analysis with introductory statistical methods, including correlation and regression.
9. [Statistics – Core Concepts](09-statistics-core-concepts/index.md) - Focuses on core statistical concepts, probability, and hypothesis testing.
10. [Miscellaneous Topics](10-miscellaneous-topics/index.md) - Covers miscellaneous concepts that span multiple domains and provide broader mathematical context.

## How to Use This Textbook

Students should progress through the chapters in order, ensuring they have mastered each chapter before moving to the next. Dependencies are respected, so concepts build on each other.

---

**Note:** Each chapter includes a list of concepts covered. Make sure to complete prerequisites before tackling advanced chapters.
