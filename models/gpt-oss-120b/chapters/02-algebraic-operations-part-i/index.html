    Completing the Square¶

    Completing the square rewrites a quadratic expression in the form \((x - h)^2 + k\), useful for solving equations and graphing parabolas. It builds on knowledge of exponents and algebraic manipulation.

    Worked Example: Solve \(x^2 + 6x + 5 = 0\). 1. Move the constant: \(x^2 + 6x = -5\). 2. Add \((6/2)^2 = 9\): \(x^2 + 6x + 9 = 4\). 3. Factor: \((x + 3)^2 = 4\). 4. Square‑root: \(x + 3 = \pm 2\). 5. Solutions: \(x = -1\) or \(x = -5\).

    Linear Equations¶

    Linear equations relate two variables with a constant slope. Mastery of solving one‑step to multi‑step linear equations is foundational for algebra.

    Worked Example: Solve \(3x + 7 = 22\). 1. Subtract 7: \(3x = 15\). 2. Divide by 3: \(x = 5\).

    One‑Step Equations¶

    One‑step equations involve a single operation to isolate the variable. They reinforce understanding of inverse operations.

    Worked Example: Solve \(x - 4 = 9\). 1. Add 4 to both sides: \(x = 13\).

    Two‑Step Equations¶

    Two‑step equations require two inverse operations, typically a combination of addition/subtraction and multiplication/division.

    Worked Example: Solve \(5x - 3 = 22\). 1. Add 3: \(5x = 25\). 2. Divide by 5: \(x = 5\).

    Multi‑Step Equations¶

    Multi‑step equations involve three or more operations, combining distributive property, combining like terms, and inverse operations.

    Worked Example: Solve \(2(x + 4) = 18\). 1. Distribute: \(2x + 8 = 18\). 2. Subtract 8: \(2x = 10\). 3. Divide by 2: \(x = 5\).

    Literal Equations¶

    Literal equations solve for a variable expressed in terms of other variables. They reinforce algebraic rearrangement skills.

    Worked Example: Solve for \(a\) in \(2a + 3b = 12\). 1. Subtract \(3b\): \(2a = 12 - 3b\). 2. Divide by 2: \(a = 6 - \frac{3b}{2}\).

    Solving for Variables¶

    Solving for variables often involves rearranging formulas to express one variable in terms of others, a skill critical for physics and chemistry contexts.

    Worked Example: Rearrange \(F = ma\) to solve for \(m\). 1. Divide both sides by \(a\): \(m = \frac{F}{a}\).

    Inequalities¶

    Inequalities compare expressions using symbols like \(<, >, \le, \ge\). Solving them follows similar steps to equations but with attention to direction when multiplying or dividing by negative numbers.

    Worked Example: Solve \(3x - 5 > 7\). 1. Add 5: \(3x > 12\). 2. Divide by 3: \(x > 4\).

    Linear Inequalities¶

    Linear inequalities are similar to linear equations but represent ranges of solutions.

    Worked Example: Solve \(2x + 3 \le 11\). 1. Subtract 3: \(2x \le 8\). 2. Divide by 2: \(x \le 4\).

    Absolute Value Equations¶

    Absolute value equations involve expressions within \(|\cdot|\) and require splitting into two cases.

    Worked Example: Solve \(|x - 2| = 5\). 1. Case 1: \(x - 2 = 5 \Rightarrow x = 7\). 2. Case 2: \(x - 2 = -5 \Rightarrow x = -3\).

    Absolute Value Inequalities¶

    Absolute value inequalities describe ranges of values around a central point.

    Worked Example: Solve \(|x + 1| < 4\). 1. Remove absolute value: \(-4 < x + 1 < 4\). 2. Subtract 1: \(-5 < x < 3\).

    Graphing Lines¶

    Graphing linear equations involves plotting the set of points that satisfy the equation. The slope‑intercept form \(y = mx + b\) is particularly useful.

    Worked Example: Graph \(y = 2x - 3\). 1. Identify slope \(m = 2\) and intercept \(b = -3\). 2. Plot the y‑intercept at \((0, -3)\). 3. From that point, rise 2 and run 1 to find another point \((1, -1)\). 4. Draw the line through the points.

    Slope¶

    Slope measures the steepness of a line and is defined as \(\frac{rise}{run}\). It indicates how much \(y\) changes for a unit change in \(x\).

    Worked Example: Find the slope of the line passing through \((2,3)\) and \((5,11)\). [m = \frac{11 - 3}{5 - 2} = \frac{8}{3}]

    Y‑Intercept¶

    The y‑intercept is the point where a line crosses the y‑axis (\(x = 0\)). It is the constant term \(b\) in \(y = mx + b\).

    Worked Example: Find the y‑intercept of \(y = -4x + 7\). Set \(x = 0\): \(y = 7\).

    X‑Intercept¶

    The x‑intercept is where a line crosses the x‑axis (\(y = 0\)). It is found by setting \(y = 0\) and solving for \(x\).

    Worked Example: Find the x‑intercept of \(y = 3x - 9\). Set \(0 = 3x - 9\) ⇒ \(x = 3\).

    Slope‑Intercept Form¶

    The slope‑intercept form \(y = mx + b\) expresses a line using its slope \(m\) and y‑intercept \(b\). It is convenient for graphing.

    Worked Example: Convert \(2x - y = 4\) to slope‑intercept form. 1. Solve for \(y\): \(-y = -2x + 4\). 2. Multiply by \(-1\): \(y = 2x - 4\).

    Point‑Slope Form¶

    Point‑slope form \(y - y_1 = m(x - x_1)\) defines a line using a point \((x_1, y_1)\) and slope \(m\).

    Worked Example: Write the equation of the line with slope \(3\) passing through \((2,5)\). [y - 5 = 3(x - 2)] Simplify if desired: \(y = 3x - 1\).

    Standard Form (Lines)¶

    Standard form \(Ax + By = C\) expresses a line with integer coefficients. It is useful for certain algebraic methods.

    Worked Example: Convert \(y = -\frac{2}{3}x + 4\) to standard form. 1. Multiply by 3: \(3y = -2x + 12\). 2. Rearrange: \(2x + 3y = 12\).

    Parallel Lines¶

    Parallel lines have equal slopes and never intersect. Their equations share the same \(m\) value.

    Worked Example: Determine if \(y = 2x + 1\) and \(3y = 6x - 9\) are parallel. 1. Rewrite second equation: \(y = 2x - 3\). 2. Both have slope \(2\) ⇒ parallel.

    Perpendicular Lines¶

    Perpendicular lines intersect at a right angle; their slopes are negative reciprocals (\(m_1 \cdot m_2 = -1\)).

    Worked Example: Find the slope of a line perpendicular to \(y = -\frac{1}{2}x + 3\). The perpendicular slope is \(2\) (negative reciprocal).
