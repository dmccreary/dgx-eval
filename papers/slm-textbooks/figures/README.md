# Figures for the SLM Textbook-Generation Paper

All figures are PNG at 300 dpi, colored with the Okabe-Ito colour-blind-safe
palette, and generated by one script:

```bash
/usr/local/Caskroom/miniforge/base/envs/mkdocs/bin/python src/reporting/make_paper_figures.py
```

The script lives in `src/reporting/` because it reads the evaluation's scored
output; see `src/README.md`. It writes these files and
`../data/paper-numbers.json`.

| File | Paper reference | Section | What it shows | Data |
|---|---|---|---|---|
| `fig-book-structure.png` | `fig:book` | 3 The Book | Concepts and words per chapter, colored by part | `docs/chapters/*/index.md` |
| `fig-architecture.png` | `fig:architecture` | 4 Benchmark Design | Orchestrator, harness, model, and what crosses each boundary | Drawn; no data |
| `fig-completion.png` | `fig:completion` | 6 Results | How far each of the ten candidates got in each stage | `data/stage-metrics.csv`, `docs/models/` |
| `fig-time.png` | `fig:time` | 6 Results | Machine time by stage, with runs stopped at the limit | `data/stage-metrics.csv` |
| `fig-quality.png` | `fig:quality` | 6 Results | Level against consistency, and every chapter's score | `src/scoring/chapter_quality.py` output |
| `fig-cost-sensitivity.png` | `fig:cost` | 7 Cost | One-at-a-time sensitivity of the cost of a book | Cost model restated in the script |

## Quality Standards

- PNG only, 300 dpi, under 1 MB each
- Readable at the 6.5 inch text width
- Colour-blind-safe palette, with meaning also carried by labels
- No address, host name, or login; the architecture diagram names machines only
  as roles
- Each figure is cited in the text and has a caption that stands alone

## Adding a Figure

1. Add a function to `src/reporting/make_paper_figures.py` and call it from
   `main()`.
2. Run the script and look at the PNG.
3. Add `\includegraphics{figures/<name>.png}` with a caption and a label.
4. Add a row to the table above.
