    Gap Analysis¶

    No rubric element scored below full points.

    Decided: the course is DGX-model-agnostic. The author confirmed on 2026-10-09 that no specific DGX model is named. The description states this in the overview and in the hardware topic. The consequence for downstream content is that the conda, probe, and model-fit chapters must cover both x86_64 and aarch64 CPUs and both dedicated GPU memory and unified memory, with the probe report deciding which branch a reader follows.

    Added: sanitization before publication. On 2026-10-09 the author asked for a sanitization topic, because the book is public and the tested DGX is a real machine. Topic 16 and one outcome at each of the Remember, Understand, Apply, and Evaluate levels cover it. The probe-suite outcome now redacts identifying fields by default, and the capstone sanitizes every artifact before publishing.

    Three decisions are still open. None of them blocks concept enumeration, but each one changes specific chapters.

    1. The model and harness lists are candidates, not selections. The software-stack table names model families and four agent harnesses as examples. Whether each harness loads the ibook-skills skills unmodified against a local endpoint has not been tested and is itself part of the evaluation.
    2. The cloud baseline is not fixed. Four cloud services are named for the pros-and-cons discussion. The benchmark needs one specific model and harness as the quality reference.
    3. The benchmark book is not chosen. The capstone generates "a small intelligent textbook". The subject and size of that book determine run time and cost per chapter.

    Improvement Suggestions¶

    Listed in order of impact on downstream content.

    1. Pick the cloud baseline (one model, one harness) and add it to the Objective evaluation methodology topic.
    2. Choose the benchmark book and record its subject, target concept count, and chapter count.
    3. After the first probe run, replace the model-family examples with the shortlisted models that fit the measured GPU memory.
