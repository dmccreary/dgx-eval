    Glossary Quality Report¶

    This report covers the glossary, which defines all 506 concepts in the concept list. The checks below are mechanical: a script measured length, structure, cross-references, and content rules. Precision and distinctiveness cannot be scored by a script, so those two criteria rest on a spot check of 20 entries, not on a full review.

    Input Quality¶

    Check Result
    Concepts in the list 506
    Duplicate labels 0
    Labels over 32 characters 0
    Labels not in Title Case 31, all literal tool, command, or model names such as nvidia-smi, vLLM, and gemma4:31b, kept as written

    Coverage¶

    Check Result
    Concepts with an entry 506 of 506
    Entry headers that match a concept label exactly 506 of 506
    Entries not in the concept list 0
    Alphabetical order (case-insensitive) 100%

    ISO 11179 Criteria¶

    Criterion How it was checked Result
    Conciseness Definition word count against the 20-50 word target Average 28.8 words; shortest 20, longest 42; none outside the target
    Non-circularity Whether a multi-word term appears verbatim in its own definition 0 entries
    Free of business rules Search for must, should, always, never, and similar words 6 hits, each reviewed; all describe what a thing does (for example "the device has to sign in again") and none prescribes practice
    Distinctiveness Word-overlap comparison of every pair of definitions No pair above 0.55 similarity
    Precision Spot check of 20 entries against the chapters, including every candidate-model entry No factual conflict found; model entries state identity and publisher claims only, and carry no test outcomes or rankings

    Content Safety Checks¶

    The book is public and the device under test is real, so the glossary was scanned for the details listed in the repository's security rules.

    Check Result
    IPv4 or IPv6 addresses outside the documentation range 0
    MAC-address-like strings, token-like strings, or tailnet names 0
    Home-directory paths, user@host strings, or password assignments 0
    Dollar signs (rendered as math by the site) 0
    Placeholders used <dgx-host>, <user>, <tailnet-name>.ts.net, 100.x.y.z, 192.0.2.0/24

    Recommendations¶

    • Add examples where coverage is lowest. Local SLMs Versus Cloud LLM Services, AI Agent Harnesses and Skills, and Prerequisite Skills sit below 45%. These are mostly definitional terms, so the gap is acceptable, but an example would help a reader meeting an agent-harness term for the first time.
    • Re-read the book-coined terms after the chapters change. Entries such as Standing Approval Answer, Text-Emitted Tool Call, and Data Egress Trace were written to match how the chapters use them. If a chapter redefines one of these, update the entry in the same change.
    • Keep model entries free of results. Test outcomes are provisional, so the candidate-model entries describe identity and role only. A rewrite that adds speeds or rankings would put provisional numbers in a permanent reference.
    • Run a human review of precision. The 20-entry spot check is not a substitute for the Primary Author reading the entries in their own topic areas.
